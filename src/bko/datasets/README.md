# `bko.datasets`: dataset loading

Load the evaluation datasets: UCI Heart Disease, the primary heart-disease prediction task; Synthea, the population used to test gap detection by ablating selected cases; and UCI Diabetes 130-US Hospitals, the real encounters for subgroup removal.

UCI Heart Disease loads as its complete Cleveland records, split into training and test records,
with the age-sex subgroup-label cells of the training records counted (ADR [`research/uci-evaluation-frame`](../../../docs/adr/research/uci-evaluation-frame.md)), and a share of each cell's training records kept for a scarcity run (`bko.datasets.split.subsampled`, ADR [`research/e1-evaluation-protocol`](../../../docs/adr/research/e1-evaluation-protocol.md)). The values that define the data are constants in this package, and the ones the stages read are held together in one frame value, `bko.datasets.frames.FrameSpec`, whose UCI instance is `bko.datasets.uci.UCI_FRAME`, with UCI's numeric ranges (`RANGES`); the command and the `data/` layout are in [`docs/DEVELOPMENT.md`](../../../docs/DEVELOPMENT.md#data). Synthea loads as a pinned generated population, from which an ablation removes chosen patients as ground truth (ADR [`research/synthea-ablation-design`](../../../docs/adr/research/synthea-ablation-design.md)). The same population is E3's frame: `bko.datasets.synthea.frame_records` reads one record per patient alive on the snapshot date and aged 40 and over, with age, sex, a 0/1 indicator per mapped condition and the ischemic heart disease label, and `bko.datasets.ablation.thinned` removes a share of one cell's training rows by the ablation's draw (ADR [`research/synthea-downstream-design`](../../../docs/adr/research/synthea-downstream-design.md)); `bko.ontology.frames` holds the frame's `FrameSpec`. Diabetes 130-US Hospitals is pinned as `bko.datasets.sources.DIABETES_130`, open under CC BY 4.0; `bko.datasets.diabetes` reads one adult record per patient's first encounter with the 30-day readmission label, and never the archive's `encounter_id` or `patient_nbr` (the frame contract is in [`docs/DEVELOPMENT.md`](../../../docs/DEVELOPMENT.md#data), The Diabetes frame). On request it keeps the three diagnosis codes as integers instead of category indicators, under the reversible encoding of `bko.datasets.diagnoses`, for the `diabetes-codes` frame (ADR [`research/diabetes-diagnosis-codes`](../../../docs/adr/research/diabetes-diagnosis-codes.md)); `bko.datasets.archive` reads the archive's members with a size cap. `bko.datasets.tableshift` rebuilds TableShift's Hospital Readmission partition of the same archive in numpy, and `bko.datasets.tableshift_frame` holds its `tableshift` frame, built from the kept rows (ADR [`research/tableshift-comparison`](../../../docs/adr/research/tableshift-comparison.md); [`docs/DEVELOPMENT.md`](../../../docs/DEVELOPMENT.md#data), The TableShift frame). `bko.datasets.hd` reads Lautrup et al.'s heart-disease files as records of the UCI frame (ADR [`research/syntheval-reading`](../../../docs/adr/research/syntheval-reading.md)). It also pins the MONDO, HPO and DO releases that `bko.ontology` reads, and the MONDO and HPO OWL files and the ROBOT jar that its `elk` command reads (`MONDO_OWL`, `HPO_OWL`, `ROBOT_JAR`).

- **Dependencies:** The `data` extra (`pyproject.toml`).
- **Status:** built.
