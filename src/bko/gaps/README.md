# `bko.gaps`: gap detection

Find statements the ontology implies but the data does not support. The 2-pager states that Santos et al. prove these ungrounded statements contribute nothing to the model's distribution, so the plan uses them as the formal definition of a dataset gap. Count-based gaps are detected and evaluated separately.

- **Dependencies:** No optional extra.
- **Owner:** Partiban Anathurai
- **Status:** not built; the package holds only its docstring. Planned in [`proposal-gap-detection`](../../../tasks/proposal-gap-detection.md).
