# `bko.baselines`: baseline augmentation

The comparison methods, at equal row counts: no augmentation, class weighting, SMOTE and ADASYN (imbalanced-learn), CTGAN, TVAE and the Gaussian copula (SDV), TabDDPM's Gaussian and multinomial diffusion written in-house in torch (`bko.baselines.ddpm`, `bko.baselines.diffusion`; ADR [`research/diffusion-baseline`](../../../docs/adr/research/diffusion-baseline.md)), sequential CART (scikit-learn), a label bootstrap that copies whole label-group records into the cell, a Bayesian network learned in-house by PrivBayes' GreedyBayes search (`bko.baselines.bayes_net`; ADR [`research/bayesian-network-baseline`](../../../docs/adr/research/bayesian-network-baseline.md)), and E19's retained-data methods, each refusing a request by label (ADR [`research/matched-knowledge-controls`](../../../docs/adr/research/matched-knowledge-controls.md)): `row-resample`, `marginals` and `eb-marginals` (`bko.baselines.pooling`), which fill a cell from its own records and its band's label group by the pooled rule, a whole row, a column at a time, or a column at a time at one empirical-Bayes weight, and `hb-marginals` (`bko.baselines.multilevel`, its fit in `bko.baselines.multilevel_fit`), which draws each column but `age` and `sex` from a fitted multilevel multinomial logit and `age` by the pooled rule, the model specified in that ADR's Decision 7. `bko.baselines.categories` gives the categories `eb-marginals` and `hb-marginals` count a column in. `bko.baselines.conditional` redraws chosen columns of given rows by that sequential CART, each value from a same-leaf training donor it names; the direct arm `bko-coherent` uses it (ADR [`research/free-field-synthesis`](../../../docs/adr/research/free-field-synthesis.md)).

Each method reads the training split `bko.datasets` computes and fills exactly the rows per stratum
it is asked for, so methods given one request meet equal row counts stratum by stratum; the controls
add no rows. The methods, their parameters and the output contract are in ADR [`research/baseline-augmentation-design`](../../../docs/adr/research/baseline-augmentation-design.md); the command is in [`docs/DEVELOPMENT.md`](../../../docs/DEVELOPMENT.md#baselines).

- **Dependencies:** The `synth` extra (`pyproject.toml`).
- **Status:** built.
